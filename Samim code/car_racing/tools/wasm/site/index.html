Install on Windows

  1. Download the ZIP with the button above (Windows 10 or 11, 64-bit). Nothing else to install.
  2. Unzip it anywhere: right-click → Extract All. Don't run it from inside the ZIP.
  3. Open the folder and double-click car_racing.exe.

Windows may say "Microsoft Defender SmartScreen prevented an unrecognized app from starting". That is shown for any game not signed by a company. Click More info → Run anyway. If there is no such button, right-click car_racing.exe → Properties → tick Unblock → OK.

On a Mac? The desktop game is for Windows only for now. You can still play offline in your browser.

Race your friends

  1. One of you: ONLINE MULTIPLAYER → HOST AN ONLINE RACE, and send the 4-letter room code to the others.
  2. Everyone else: ONLINE MULTIPLAYER → JOIN WITH A CODE → type the code → Enter.
  3. The host adds CPU cars with + and starts with Enter. Your friends can be anywhere, on any Wi-Fi or mobile data.
